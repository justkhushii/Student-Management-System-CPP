# Student Management System in C++

## Introduction
The Student Management System is a simple console-based project developed using C++. It helps users add student details and view student records.

## Objectives
- To store student names, roll numbers, and marks.
- To calculate grades automatically.
- To validate marks between 0 and 100.
- To display records of multiple students.

## Features
- Add student details
- View all student records
- Automatic grade calculation
- Input validation
- Menu-driven interface

## Technologies Used
- Programming Language: C++
- Concepts: Classes, Objects, Loops, Conditional Statements, Arrays, and Functions
- Platform: OnlineGDB
- Version Control: GitHub

## How to Run
1. Open the source file `student_management.cpp`.
2. Compile the code using a C++ compiler.
3. Run the program.
4. Choose an option from the menu and enter the requested details.
